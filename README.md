# Cloud-Integrated Honeypot & Automated Malware Analysis Platform

M.Tech Cybersecurity Dissertation Project

## Project Overview
A cloud-integrated honeypot system that automatically captures 
and analyzes malware using Docker, Kubernetes, and AWS.

## Tech Stack
- Honeypot: Cowrie (SSH)
- Containers: Docker + Kubernetes
- Cloud: AWS (S3, Lambda, SQS)
- Analysis: Static + Dynamic
- Language: Python 3
