# Phase 1 Notes

## What I Am Building
A honeypot that traps attackers, captures malware they upload,
and automatically analyzes it using cloud services.

## Key Concepts Learned
- Honeypot: A decoy system designed to attract attackers
- Static Analysis: Examining malware without executing it
- Dynamic Analysis: Running malware in isolated environment
- Containerization: Packaging apps in isolated Docker containers
- Event-driven pipeline: S3 upload triggers Lambda triggers SQS
